# Reviewer access strategy

No backdoors. No `/test-login`. No universal password.

## Approach

1. Create a normal fan account controlled by the team.
2. Complete profile / onboarding so reviewer can traverse core surfaces.
3. Share credentials with Play Console **App access** section only (never commit credentials).
4. Rotate password after review window if needed.

## Notes

- Admin Center remains ADMIN-role only; do not grant ADMIN to reviewer unless explicitly required for a review scenario.
- If maintenance mode is on, disable it for the review window.
