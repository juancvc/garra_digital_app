# RC scope — feature freeze

## Allowed without extra decision

- Bug fixes
- Performance
- Security
- Copy / accessibility
- Crash fixes
- Policy / compliance plumbing
- Visual polish

## Not allowed without explicit decision

- New modules / large domains
- New monetization
- Chat / DMs / stories / video
- Payments / ticketing
- New gamification systems

Garra already has enough product surface for a controlled beta.
